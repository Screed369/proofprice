<script>
    (function () {
        function initializeNavigation() {
            var navigation = document.getElementById('navbarSupportedContent');
            var toggle = document.querySelector('#main-nav .navbar-toggler');
            var menu = navigation ? navigation.querySelector('.navbar-nav') : null;

            if (!navigation || !toggle || !menu) {
                return;
            }

            function isMobileNavigation() {
                return window.innerWidth < 992;
            }

            function isNavigationOpen() {
                return navigation.classList.contains('show') || navigation.classList.contains('collapsing');
            }

            function syncNavigationState() {
                var isOpen = isMobileNavigation() && isNavigationOpen();
                document.body.classList.toggle('navigation-open', isOpen);
                toggle.classList.toggle('is-open', isOpen);

                if (!navigation.classList.contains('collapsing')) {
                    toggle.setAttribute('aria-expanded', isOpen ? 'true' : 'false');
                }
            }

            function closeNavigation(restoreFocus) {
                if (!isMobileNavigation() || !isNavigationOpen()) {
                    return;
                }

                toggle.click();

                if (restoreFocus) {
                    window.setTimeout(function () {
                        toggle.focus();
                    }, 0);
                }
            }

            function resetDesktopState() {
                if (isMobileNavigation()) {
                    syncNavigationState();
                    return;
                }

                navigation.classList.remove('show', 'collapsing');
                navigation.style.height = '';
                document.body.classList.remove('navigation-open');
                toggle.classList.remove('is-open');
                toggle.setAttribute('aria-expanded', 'false');

                navigation.querySelectorAll('.dropdown.show').forEach(function (dropdown) {
                    dropdown.classList.remove('show');
                    var dropdownToggle = dropdown.querySelector('.dropdown-toggle');
                    var dropdownMenu = dropdown.querySelector('.dropdown-menu');

                    if (dropdownToggle) {
                        dropdownToggle.setAttribute('aria-expanded', 'false');
                    }

                    if (dropdownMenu) {
                        dropdownMenu.classList.remove('show');
                    }
                });
            }

            new MutationObserver(syncNavigationState).observe(navigation, {
                attributes: true,
                attributeFilter: ['class']
            });

            document.addEventListener('click', function (event) {
                if (!isMobileNavigation() || !isNavigationOpen()) {
                    return;
                }

                if (menu.contains(event.target) || toggle.contains(event.target)) {
                    return;
                }

                closeNavigation(false);
            });

            document.addEventListener('keydown', function (event) {
                if (event.key === 'Escape') {
                    closeNavigation(true);
                }
            });

            window.addEventListener('resize', resetDesktopState);
            toggle.addEventListener('click', function () {
                window.requestAnimationFrame(syncNavigationState);
            });

            resetDesktopState();
        }

        if (document.readyState === 'loading') {
            document.addEventListener('DOMContentLoaded', initializeNavigation);
        } else {
            initializeNavigation();
        }
    })();
</script>

<p>As diferenças na fatura de eletricidade entre o mercado regulado e o mercado liberalizado podem resumir-se assim:</p>
<p><img class="image-responsive" src="/media/xt1nna1t/tabela_liberalizado_regulado_nov23_pt.svg?rmode=max&amp;width=655&amp;height=246" alt="Imagem que demonstra as diferenças do Mercado Liberalizado e o Mercado Regulado"></p>
<p>A tarifa de Acesso às Redes é paga por todos os consumidores, independentemente de estarem no mercado regulado ou no mercado liberalizado e reflete o custo das infraestruturas e dos serviços utilizados por todos os consumidores de forma partilhada. Esta tarifa resulta da soma das tarifas de Uso Global do Sistema, de Uso da Rede de Transporte e de Uso da Rede de Distribuição, todas fixadas pela ERSE.</p>
<p>A tarifa de Energia e a tarifa de Comercialização, fixadas pela ERSE, apenas são pagas pelos consumidores que ainda estão no mercado regulado. No mercado liberalizado, o valor correspondente é definido por cada comercializador de forma livre e em concorrência com os outros comercializadores.</p>
<p>As taxas e impostos (por exemplo, o IVA) são definidas pelo Estado e iguais em ambas as situações.</p>
<p>Para saber mais sobre as ofertas comerciais no mercado liberalizado consulte o <a rel="noopener" href="https://www.erse.pt/biblioteca/atos-e-documentos-da-erse/?tipologia=----+Ofertas+Comerciais&amp;setor=Eletricidade&amp;ano=&amp;descricao=" target="_blank" data-anchor="?tipologia=----+Ofertas+Comerciais&amp;setor=Eletricidade&amp;ano=&amp;descricao=">Boletim das Ofertas Comerciais de eletricidade</a><a rel="noopener" href="https://www.erse.pt/eletricidade/supervisao-do-mercado/boletins-e-resumos-informativos/" target="_blank">.</a></p>

<p>O preço da energia elétrica tem preços diferentes consoante a hora a que se realiza o consumo.</p>
<p>O período horário corresponde à forma como o consumo de eletricidade se distribui ao longo das 24 horas de cada dia e dos 7 dias da semana.</p>
<p>Os períodos horários de entrega de energia elétrica, previstos no <a href="/atividade/regulamentos-eletricidade/tarifario/">Regulamento Tarifário</a>, nos artigos 34.º para Portugal continental e artigo 40.º para as Regiões Autónomas, são os seguintes:&nbsp;</p>
<ul>
<li><span class="yellow">Ponta:</span> aplicável a consumidores de todos os níveis de tensão e a consumidores em baixa tensão normal&nbsp; (BTN) que tenham a tarifa tri-horária. Corresponde ao período em que o preço da energia é mais elevado.</li>
<li><span class="yellow">Cheias:</span> aplicável a consumidores de todos os níveis de tensão e a consumidores em BTN que tenham a tarifa tri e bi-horária.</li>
<li>&nbsp;<span class="yellow">Vazio normal:</span> aplicável a consumidores de todos os níveis de tensão e a consumidores em BTN que tenham a tarifa tri ou bi-horária. Corresponde ao período em que o preço da energia é mais reduzido.&nbsp;</li>
<li>&nbsp;<span class="yellow">Super vazio: </span>aplicável a consumidores ligados em baixa tensão especial (BTE), média tensão (MT), alta tensão (AT) e muito alta tensão (MAT).</li>
</ul>
<p>Além dos períodos horários, também estão previstos dois ciclos: <strong>ciclo diário</strong> (os períodos horários são iguais em todos os dias do ano) e <strong>ciclo semanal</strong> (os períodos horários diferem entre dias úteis e fim de semana).</p>
<p>Para cada ciclo há um horário de verão e de inverno, que reflete a alteração da hora legal.</p>
<p>Os períodos horários em Portugal Continental e nas Regiões Autónomas são determinados pelas especificidades elétricas de cada região, designadamente pela evolução do seu diagrama de carga.</p>
<p>Um consumidor de energia elétrica em BTN (potências contratadas inferiores ou iguais a 41,4 kVA) pode escolher entre 3 opções tarifárias. Cada período apresenta diferentes preços de energia:</p>
<ul>
<li><strong>Tri-horário</strong>: 3 períodos durante o dia (horas de ponta, horas cheias e horas de vazio)</li>
<li><strong>Bi-horário</strong>: 2 períodos durante o dia (horas fora de vazio e horas de vazio)</li>
<li><strong>Simples</strong>: 1 único período durante o dia, sem diferenciação do preço de energia.</li>
</ul>
<p>Para mais informação consulte o <a href="/simuladores/precos-de-energia/">simulador de preços de energia</a> da ERSE.</p>
<p><span class="yellow titulo">Novos períodos horários a partir de abril de 2027</span></p>
<p>A partir de abril de 2027 são aplicáveis novos períodos horários em Portugal continental. A alteração realiza-se de forma faseada, da seguinte forma:</p>
<ul>
<li>Em data única, a 1 de abril de 2027, para os clientes com instalações ligadas em BTE,<br>MT, AT e MAT (essencialmente do segmento não residencial);</li>
<li>Entre 1 de julho e 31 de dezembro de 2027 para as instalações em BTN com opção<br>bi-horária ou tri-horária (clientes residenciais ou pequenos negócios).</li>
</ul>
<p>A alteração decorrerá automaticamente, sendo preferencialmente realizada de forma&nbsp;remota pelo operador de rede através do contador inteligente.</p>
<p>Os novos períodos horários aplicáveis às tarifas de acesso às redes e às fornecimento assegurado pelo comercializador de último recurso, foram aprovados através da <a rel="noopener" href="/media/3hanbooq/diretiva-nº-3_2026-19-de-agosto-aprova-os-períodos-horários.pdf" target="_blank" title="Diretiva N.º 3 2026, 19 De Agosto">Diretiva n.º 3/2026</a>, de 19 de agosto, retificada pela <a rel="noopener" href="/media/wxjme3wb/dr-889_2026_2-periodos-horários.pdf" target="_blank" title="DR 889 2026 2 Periodos Horários">Declaração de Retificação n.º 889/2026/2</a>, de 19 de outubro.</p>
