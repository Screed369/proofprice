                  <s-fragment id="2" class="psml-fragment col-12" data-labels="" fragment-id="2" fragment-title="&#xA;API infoEmbargo APIPublic APIAPI FAQ&#xA;" color="" :on-footer="false">

                     <p id="fragment-2-toc-1">The Department of Health, Disability and Ageing has developed an API for the efficient
                        distribution of PBS schedule data. This API contains the full dataset of the PBS Schedule,
                        including details of the medicines subsidised by the Australian Government and the
                        conditions for their prescribing and dispensing. The PBS Schedule and the data in
                        the API is updated on the first day of every month.</p>
                     <p id="fragment-2-toc-2">Users can access the API endpoints, retrieve all data associated with a Schedule and
                        download that file to their local storage ready for upload into their own systems/databases.</p>
                     <p id="fragment-2-toc-3">The API has not been designed as a high-volume real-time system, but rather as a data
                        storage and retrieval system to enable users the ability to download and store local
                        copies of the data.</p>
                  </s-fragment>
                  <s-fragment id="3" class="psml-fragment col-12" data-labels="" fragment-id="3" fragment-title="Features of the API" color="" :on-footer="false">
                     <h2 class=" heading-2" id="fragment-3-toc-1" data-prefix="">Features of the API</h2>
                     <ul class="list list--unordered">
                        <li class="list__item">The PBS schedule data has been loaded into a relational database</li>
                        <li class="list__item">There is one API endpoint for each table in the database</li>
                        <li class="list__item">There is one logical set of data in the API for each combination of PBS item code
                           and Trade Product Pack</li>
                        <li class="list__item">Every effective PBS schedule for the most recent 12 months is in the API</li>
                        <li class="list__item">Data can be downloaded in JSON and CSV formats</li>
                        <li class="list__item">Each month is distinguished in the API by a ‘schedule code’</li>
                        <li class="list__item">The ‘schedules’ endpoint in the API has metadata about each schedule code</li>
                        <li class="list__item">Each API request can be filtered by schedule code, PBS program and PBS item code</li>
                        <li class="list__item">The API uses open standards (REST, JSON, CSV) and will work with any REST API tool.</li>
                        <li class="list__item">A limit of one request per second has been implemented for the embargo API</li>
                        <li class="list__item">The public API is rate-limited to one request per twenty seconds - this limit is shared
                           amongst all concurrent users of the PBS public API.</li>
                        <li class="list__item">As per standard modelling rules, data lives in its most natural location with associative
                           tables resolving any many-to-many relationships, and reference tables used to reduce
                           redundant storage.</li>
                     </ul>
                  </s-fragment>
                  <s-fragment id="4" class="psml-fragment col-12" data-labels="" fragment-id="4" fragment-title="PBS API - public or embargo" color="" :on-footer="false">
                     <h2 class=" heading-2" id="fragment-4-toc-1" data-prefix="">PBS API - public or embargo</h2>
                     <p id="fragment-4-toc-2">There are two API access&nbsp;options available;&nbsp;</p>
                     <p id="fragment-4-toc-3"><b>1. PBS ‘public’ API</b> - This API always displays the current PBS Schedule data and is freely available
                        to everyone. This API is updated on the first day of every month. Users wishing to
                        access the public version of the API can use the&nbsp;<a href="/api/api-public.html" class="link link222"><span class="link__content">following guidance</span></a>.</p>
                     <p id="fragment-4-toc-4"><b>2. PBS ‘embargo’ API</b> (early access) - This API provides early access to software vendors for the purposes
                        of updating prescribing, dispensing and claiming software prior to a new Schedule’s
                        date of effect. Software vendors can apply to access this API by using the <a href="/api/api-embargo.html" class="link link222"><span class="link__content">following guidance</span></a>.</p>
                  </s-fragment>
