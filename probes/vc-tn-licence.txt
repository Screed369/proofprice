        <h2 id="description">Beschrijving</h2>
        <div class="characteristics">
          
          
          
          
          
          
          
                  </div>
        <div><p>Alle aankondigingen op TenderNed zijn openbaar, zodat de gegevens voor iedereen beschikbaar zijn. U kunt de actuele aankondigingen op verschillende manieren bekijken:</p>
<ul>
<li>
<p><strong>Via het aankondigingenplatform van TenderNed</strong> - http://https://www.tenderned.nl/aankondigingen/overzicht</p>
</li>
<li>
<p><strong>Via een RSS-feed</strong> - https://www.tenderned.nl/papi/tenderned-rs-tns/rss/laatste-publicatie.rss</p>
</li>
<li>
<p><strong>Via een publicatie Webservice (TNS)</strong> - https://www.tenderned.nl/papi/tenderned-rs-tns/v2/publicaties?page=0&amp;size=20 (houd er rekening mee dat deze Webservice zonder voorafgaande kennisgeving gewijzigd kan worden)</p>
</li>
<li>
<p><strong>Via de TenderNed API</strong></p>
</li>
</ul>
<h3>TenderNed API</h3>
<p>Via de TenderNed API kunt u real-time aankondigingen downloaden in XML-formaat. Om onze API te gebruiken, heeft u een gebruikersnaam en wachtwoord nodig. Vraag deze aan via functioneelbeheer@tenderned.nl. De instructie van de XML API wordt bij elke release automatisch geüpdatet: https://www.tenderned.nl/info/swagger/.
Er is een codevoorbeeld beschikbaar om u op weg te helpen. Deze is te vinden op Github: https://github.com/tenderned-analyse/code-example-tn-xml-api/</p>
</div>
