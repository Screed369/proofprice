                    <h2 class="h2">API Informationen</h2>
                    <hr/>
                    <p class="small-margin">
                        Die Tankerkönig-API besteht aus drei HTTP-GET-Methoden, um Tankstellen-Informationen und
                        Preise zu holen, sowie einer HTTP-POST-Methode, mit der fehlerhafte Daten an die MTS-K gemeldet
                        werden können.
                    </p>
                    <p class="small-margin">
                        Die API kann von einem Server (z.B. über PHP), vom Browser (via JavaScript/AJAX) oder auch per
                        Direktaufruf der URL (ideal zum Testen) abgefragt werden. Als Datenformat wird JSON
                        zurückgeliefert.
                    </p>

                    <h3 class="h3">Demo-Key</h3>
                    <p class="small-margin">
                        Die Beispielaufrufe hier werden mit dem Demo-Key gemacht. Im Unterschied zu echten Keys
                        werden keine echten Preise ausgeliefert. Außerdem sind die Daten zur besseren Lesbarkeit
                        formatiert.
                    </p>

                    <h3 class="h3">Requests allgemein</h3>
                    <div class="small-margin">
                        In jedem Aufruf einer API-Methode muss ein API-Key mit angegeben werden. <br>
                        Die Antwort enthält immer ein <code>ok</code> flag, dessen Status abgefragt werden sollte. Im
                        Fehlerfall (ok == false) enthält die Antwort einen Text mit der Fehlerursache, bspw:
                        <div class="h10"></div>
<pre>
{
  "ok":false,
  "message":"parameter error"
}
</pre>
                        Es ist sinnvoll und dringend empfohlen, immer das ok-Flag abzufragen um zu testen, ob der
                        Aufruf erfolgreich war. <br>
                        Je nach Applikation sollte der Fehler entsprechend behandelt werden, etwa so:
                    </div>
                    <ul class="small-margin-top">
                        <li>Fehlertext anzeigen,</li>
                        <li>Fehlertext an Server melden, falls ein eigener Server eingesetzt wird,</li>
                        <li>Keine weiteren Requests mehr senden</li>
                    </ul>
