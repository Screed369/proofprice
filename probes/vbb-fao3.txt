      <div id="maincontent" class="main-internal"><div id="c366583" class="csc-default" ><div class="csc-header csc-header-n1"><h1 class="csc-firstHeader">FPMA Tool</h1></div><div class="csc-textpic-text"><p class="bodytext">The Food Price Monitoring and Analysis (FPMA) Tool is an advanced technical solution for dissemination and analysis of price information. The first version of the tool was released in March 2009 as part of FAO’s initiatives to address the soaring food prices at that time. Several iterations of the tool since then have introduced enhanced analysis features and ensured that the tool is up to date with latest technologies. The most recent version of the tool (version 4) was released in mid-2022.</p>
<p class="bodytext">&nbsp;<img src="/fileadmin/user_upload/foodprice/img/price_tool/FPMA-Tool-V4.png" width="480" height="242" alt="" /></p>
<p class="bodytext">The user friendly interface allows users to scan current and past prices, check basic statistics such as percentage changes, and make comparisons across markets, commodities and seasons. The tool also incorporates a feature for the calculation of the <a href="https://www.fao.org/sustainable-development-goals/indicators/2.c.1/en/" target="_blank" >Sustainable Development Goals (SDG) Indicator 2.c.1</a>, which measures the number of “Price Anomalies” that occur on a given food commodity price series over a given period of time. This indicator is being used to measure progress towards <a href="https://www.fao.org/sustainable-development-goals/indicators/2.c.1/en/" target="_blank" >SDG Target 2.c</a>. </p>
<p class="bodytext">The FPMA Tool is available to countries and regional organizations. It can be linked to existing systems that collect food price data, and tailored to meet specific needs. </p>
<p class="bodytext">As of 2023, the FPMA Tool system also incorporates an optional component for primary price data collection through a mobile app. The collected data can subsequently be validated and pushed to the analysis and dissemination platform.</p>
<p class="bodytext">&nbsp;<img src="/uploads/RTEmagicC_Collection-App-1.png.png" width="200" height="404" alt="" /></p>
<p class="bodytext">See a short video about the tool <a href="https://www.youtube.com/watch?v=sZx3hhnEHiI" title="Opens external link in new window" target="_blank" class="external-link-new-window" >here</a>.</p>
