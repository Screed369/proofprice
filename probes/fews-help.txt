	<p>This page discusses the processes for preparing and uploading prices data to the FEWS NET Data Warehouse (FDW). It covers the steps for adding historical data to FDW for a new data source, as well as the routine processes for uploading monthly or weekly data collections.</p>
<h2 id="Historical-data" style=""><span id="Prices-Historicaldata"></span>Historical data
 <i18n-message i18nkey="clipboard.copyLink.label" attribute="description">
  <copy-clipboard class="anchor-copy-button" value="https://help.fews.net/fdw/prices#Historical-data">
   <svg role="img" aria-hidden="true" data-component="icon" class="icon icon-link copy-headline-link-icon">
    <use href="/__theme/b_8ca5a7d7-80f3-41c8-bea7-75cce14ad14f/scroll-sites-help-center-theme/57/icons.svg#link"></use>
   </svg>
  </copy-clipboard>
 </i18n-message></h2>
<p>Before FDW can ingest a new prices data source, you must do the following:&nbsp;</p>
<ul>
 <li>
  <p>Identify new metadata, such as new markets or products, and add it to FDW.</p>
 </li>
 <li>
  <p>Prepare a file containing the historical data that has been cleaned and organized using an upload template built for price recognition.&nbsp;</p>
  <ul>
   <li>
    <p>The historical data file will be used as the basis for a new upload file for the field to begin adding their prices monthly or weekly.</p>
   </li>
  </ul>
 </li>
</ul>

    <use href="/__theme/
