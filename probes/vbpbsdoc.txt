                     <p id="fragment-2-toc-1">The PBS public API displays the current PBS Schedule data and is freely available
                        to everyone, no login is required. This API is rate-limited to one request per twenty
                        seconds - this limit is shared amongst all concurrent users of the PBS public API.
                        The past 12 months of PBS Schedule data can also be accessed from the public API.</p>
                     <p id="fragment-2-toc-2">Detailed information about the API, including definitions, examples, etc can be found
                        by selecting the current API from the <a class="link" data-labels="" href="https://data-api-portal.health.gov.au/apis"><span class="link__content">PBS API Catalogue</span></a>.</p>
                     <p id="fragment-2-toc-3">The guidance below shows one of the methods to access the PBS API data via an online
                        tool called <a class="link" data-labels="" href="http://www.postman.com/"><span class="link__content">Postman</span></a>.</p>
                     <p id="fragment-2-toc-4"><b><i>Disclaimer</i></b><i>: The Department of Health, Disability and Ageing is suggesting Postman as one of
                           many options to access the PBS API. The Department has no affiliation with Postman
                           and cannot guarantee the results produced using this product. The use of Postman is
                           solely at your own risk.</i></p>
                  </s-fragment>
                  <s-fragment id="3" class="psml-fragment col-12 step " data-labels="s-step" fragment-id="3" fragment-title="Locate the API in Postman" color="" :on-footer="false">
                     <h2 class=" heading-2" id="fragment-3-toc-1" data-prefix="1"><span class="prefix">1 </span>Locate the API in Postman</h2>
                     <p id="fragment-3-toc-2"><b>Important: </b>You will need to setup a free online account for postman before you can access the
                        API, select ‘Sign Up for Free’ within Postman and follow the prompts. Once you have
                        created your Postman account, click on the <a class="link" data-labels="" href="https://www.postman.com/hpps/workspace/pbs-public-data-api/collection/33098837-829fc4a1-741d-4807-b524-a492afe522bb?action=share&amp;creator=33098837"><span class="link__content">following link</span></a>, this will direct you to the PBS Public data API collection&nbsp;(shown in Figure 1).</p>
                     <p id="fragment-3-toc-3">The left-hand side displays the endpoints available in the API. A description of each
                        table can be found in the <i>Data Dictionary</i> available in the <a href="/api/pbs-api.html#fragment-5" class="link link222"><span class="link__content">Resources</span></a> section.</p>
                     <p id="fragment-3-toc-4">

                  <s-fragment id="5" class="psml-fragment col-12 step " data-labels="s-step" fragment-id="5" fragment-title="Load the collection into your own workspace &nbsp;" color="" :on-footer="false">
                     <h2 class=" heading-2" id="fragment-5-toc-1" data-prefix="2"><span class="prefix">2 </span>Load the collection into your own workspace &nbsp;</h2>
                     <p id="fragment-5-toc-2">In order to download the data from the API, you will need to 'fork' the collection
                        which will create a duplicate of the collection within your own workspace in Postman.
                        ‘Forking’ is a technical term for creating your own local copy of the API data. General
                        information on forks in Postman can be found in the <a class="link" data-labels="" href="https://learning.postman.com/docs/collaborating-in-postman/using-version-control/forking-elements/"><span class="link__content">Postman user guidance</span></a>.</p>
                     <p id="fragment-5-toc-3">Select the three dots next to PBS Public Data API (shown in Figure 2). Select 'Create
                        a fork' from the drop-down that appears.</p>
                     <p id="fragment-5-toc-4">
                        <s-image src="/content/image/91350" alt="Figure-2a.PNG" width="507" height="667" custom-class="" :caption="false" :zoom="false"></s-image>
                     </p>
                     <p id="fragment-5-toc-5"><i>Figure 2: drop-down menu and 'Create a fork' options highlighted</i></p>
                     <p id="fragment-5-toc-6">Selecting 'Create a fork' will open a new 'Create Fork' tab in Postman. Here you will
                        need to name your fork (name it something useful so you can find it later) and select
                        which workspace you want to add the fork to (shown in Figure 3). Postman will set
                        the fork label to your user name and the workspace to 'My Workspace' by default. Here
                        you will also have the option to select 'Watch original collection'. Ticking this
                        box will notify you when updates are made to the API or endpoints.</p>
                     <p id="fragment-5-toc-7">
                        <s-image src="/content/image/91341" alt="Figure-3a.PNG" width="994" height="774" custom-class="" :caption="false" :zoom="false"></s-image><br><i>Figure 3: Create Fork tab in Postman with Fork Label, Workspace and Notifications
                           fields highlighted.</i></p>
                     <p id="fragment-5-toc-8">Select 'Fork Collection'. This will open a duplicate of the collection in your own
                        space with the label you gave your fork (shown in Figure 4). Changes made in your
                        workspace will not flow through to the original collection from which you made your
                        fork.&nbsp;</p>
                     <p id="fragment-5-toc-9">
                        <s-image src="/content/image/91329" alt="Figure-4a.PNG" width="456" height="439" custom-class="" :caption="false" :zoom="false"></s-image><br><i>Figure 4: Fork of PBS Public Data API with fork label highlighted.</i></p>
                  </s-fragment>
                  <s-fragment id="6" class="psml-fragment col-12 step-last step " data-labels="s-step-last s-step" fragment-id="6" fragment-title="Download data from the API" color="" :on-footer="false">
                     <h2 class=" heading-2" id="fragment-6-toc-1" data-prefix="3"><span class="prefix">3 </span>Download data from the API</h2>
                     <p id="fragment-6-toc-2">Navigate to the schedules endpoint and select 'Send' (shown in&nbsp;Figure 5). This will
                        make sure that you are capturing data from the latest schedule. This step will only
                        need to be conducted at the start of the month when the latest schedule is made available.</p>
                     <p id="fragment-6-toc-3">
                        <s-image src="/content/image/91349" alt="Figure-5a.PNG" width="1638" height="303" custom-class="" :caption="false" :zoom="false"></s-image><i>Figure 5: Schedules endpoint with 'Send' highlighted.&nbsp;</i></p>
                     <p id="fragment-6-toc-4">Then navigate to any of the other endpoints you wish to download (e.g. items, fees,
                        etc,.) and select 'Send' as you did for Step 1. This will pull the data from the selected
                        endpoint into the Response field at the bottom of Postman (shown in Figure 6).</p>
                     <p id="fragment-6-toc-5">To save this as a CSV, select the three dots in the upper right corner of the response
                        section and select 'Save response to file' (shown in figure 6). The file name will
                        save as 'response.csv' by default.</p>
                     <p id="fragment-6-toc-6">
                        <s-image src="/content/image/91344" alt="Figure-6a.PNG" width="1646" height="428" custom-class="" :caption="false" :zoom="false"></s-image><i>Figure 6: Response section in Postman with 'Save response to file' highlighted.<br></i></p>
                     <p id="fragment-6-toc-7">Repeat this process for all the other endpoints you want to download.</p>
                     <p id="fragment-6-toc-8">Once you have downloaded your endpoints/files you can exit Postman and import these
                        files into a suitable software application, such as Excel.</p>
                  </s-fragment>
               </s-section>
