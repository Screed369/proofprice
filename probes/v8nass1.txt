<div>
<p>
The National Agricultural Statistics Service (NASS) offers Quick Stats, an on-line database containing official published aggregate estimates related to U.S. agricultural production. NASS develops these estimates from data collected through:
<ol style="margin:5px;list-style-type:none; padding-left:15px;">
<li>
  1) hundreds of sample surveys conducted each year covering virtually every aspect of U.S. agriculture    
</li>
<li>
  2) the Census of Agriculture conducted every five years providing state- and county-level aggregates
</li>
</ol>
</p>

<p>
The Quick Stats application programming interface (API) provides direct access to the statistical information in the Quick Stats database.  We invite developers to use this API and to give us feedback so we can continue to improve it.
</p>
<h4>About the Quick Stats API </h4>
<p>
To use the Quick Stats API, you must first agree to the <span class="menu" id="list" onclick="openDiv('disclaim', 'block');">NASS Terms of Service</span > and <span class="menu" id="list" onclick="openDiv('register', 'block');" >obtain an API key</span> In registering for the key, you must provide a valid email address. You will have the option to request future email updates about the Quick Stats API.
</p>
<p>
Once you request the API key, we will email it and you can proceed immediately. Use the key in all future data requests as well.<br>
To call the Quick Stats API, you may use either of the following:
<ul>
    <li>
       any language that supports HTTP GET request such as PHP, PERL, etc...
    </li>
    <li>
       JSON with padding or JSONP
    </li>
</ul>
</p>

<p>
Your request will return a maximum of 50,000 data records. You can determine the returned record account before you execute the Quick Stats API call using the GET /api/get_counts function. If your request will return more than the maximum limit of 50,000 data records, you can do either of the following:
<ul>
    <li>
       Change the filtering criteria (the API input parameters and their values) to generate a smaller number of responses
    </li>
    <li>
       Download <a href="https://www.nass.usda.gov/datasets/">the files</a> containing larger amounts of data extracted from the Quick Stats database.  
    </li>
</ul>

</p>

</div>

<div id='using' style="display:none">
<p>    
    <b> Using QuickStats API</b>
    <br>
    QuickStats API requests utilize input parameters based on the concept of What, Where and When.
    <ul>
    <li>
    What parameters refer to a commodity, data item or subject area.
    </li>
    <li>
    Where parameters refer to a location or geographic level such as the entire United States, state, county, district, or ZIP code.
    </li>
    <li>
    When parameters refer to a time such as year and frequency such as monthly.
    </li>
    </ul>
</p>

<p>
<b>QuickStats API Input</b>
<br>
The QuickStats API has three resources you can use to retrieve NASS published estimate data and properties, in combination with the "WHAT" and/or "WHERE" and/or "WHEN" parameters you specify. See <a href="#param_define">Parameter Definitions and Operators</a> for definitions and types.  If you have not already 
<span class="menu" id="list" onclick="openDiv('register', 'block');"> obtained an API key,</span> do so now before proceeding. 
<br>
Here are the resources, their URIs and examples:

<ol style="margin-left:10px;list-style-type:none; padding:0px;">
<li>1) GET &nbsp;/api/api_GET: accepts a combination of "WHAT" and/or "WHERE and/or "WHEN" parameters and return maximum of 50K records
<br>
<code></code>https://quickstats.nass.usda.gov/api/api_GET/?key=api key&amp;{parameter ... parameter}&format={json | csv | xml}&callback={function name}<code></code>
<br><b><i>&nbsp;&nbsp;&nbsp;&nbsp;Note:</b> callback parameter needs only for using JSONP</i>
