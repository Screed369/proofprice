    <div data-module="govspeak" class="gem-c-govspeak govuk-!-margin-bottom-8">
    
      <div class="govspeak"><p>Fuel Finder is a new government service that helps drivers find the cheapest fuel near them. It makes fuel prices available to third party apps and websites so motorists can compare prices easily.</p>

<h2 id="who-can-use-this-service">Who can use this service</h2>

<ul>
  <li>comparison websites</li>
  <li>app and website developers</li>
  <li>professional organisations</li>
  <li>academics</li>
  <li>journalists</li>
  <li>individuals</li>
</ul>

<p>If you just need fuel prices, you can find the information on participating third party apps and websites. <a href="https://www.gov.uk/government/news/fuel-finder-for-drivers-factsheet">Find out more.</a></p>

<h2 id="what-you-get">What you get</h2>

<ul>
  <li>current retail prices of all the petrol station by fuel type</li>
  <li>forecourt details (address, operator, brand)</li>
  <li>site amenities and opening hours</li>
  <li>update timestamps for each price and site</li>
</ul>

<p>Prices are published within 30 minutes of any change.</p>

<h2 id="how-to-access-the-data">How to access the data</h2>

<p>You can access the data in the following ways:</p>

<h3 id="by-downloading-the-csv-file">1. By downloading the CSV file</h3>

<p>Download a CSV file containing current prices and forecourt details (updated twice a day).</p>

<h3 id="by-subscribing-to-the-csv-file-via-email">2. By subscribing to the CSV file via email</h3>

<p>Subscribe to get a link to the latest CSV when it’s published.</p>

<h3 id="by-using-the-api">3. By using the API</h3>

<p>Use the public API by integrating the data into your own tools and services.</p>

<p>The API follows REST principles: resources have stable URLs and map to standard HTTP methods. You can read data by issuing simple GET requests to the relevant resource URL.</p>

<p>Access to API services requires authentication. The Fuel Finder API supports OAuth 2.0 (client credentials).</p>

<h2 id="before-you-start">Before you start</h2>

<p>You’ll need:</p>

<ul>
  <li>a <a href="https://www.gov.uk/using-your-gov-uk-one-login">GOV.UK One Login</a>
</li>
  <li>knowledge of your target geographic areas or specific forecourt requirements</li>
  <li>understanding of REST API principles (APIs only)</li>
  <li>technical capability to integrate with JSON APIs (APIs only)</li>
</ul>
