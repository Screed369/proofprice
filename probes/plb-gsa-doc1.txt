<h2 id="overview">Overview</h2>

<p>The CALC+ Labor Ceiling Rates tool is a pricing research tool located on buy.gsa.gov to support
government acquisition professionals in services pricing business intelligence. Acquisition staff
can use Labor Ceiling Rates data to help conduct market research with price analysis, develop
Independent Government Cost Estimates (IGCEs), and aid in benchmarking competitive pricing.</p>

<p>Access to the CALC+ Prices Paid tool begins with Pricing Central, <a href="https://buy.gsa.gov/pricing/">https://buy.gsa.gov/pricing/</a>. 
Access to this tool does not require user credentials or authentication.</p>

<p>The CALC+ Labor Ceiling Rates tool is powered by the CEILINGRATES API.</p>

<p>The CEILINGRATES API data is refreshed everyday overnight.</p>

<h2 id="entrypoint">Entrypoint</h2>

<p>The legacy URL is being retired and you should not use it.
Please see decommissioning message above.
https://api.gsa.gov/acquisition/calc/v2/api/rates/</p>

<p><strong>The URL for the CALC+ Quick Rate API is</strong></p>

<p><code class="language-plaintext highlighter-rouge">https://api.gsa.gov/acquisition/calc/v3/api/ceilingrates/</code></p>

<p>The default API URL used within our application is</p>
<div class="language-plaintext highlighter-rouge"><div class="highlight"><pre class="highlight"><code>https://api.gsa.gov/acquisition/calc/v3/api/ceilingrates/?
page=1
&amp;page_size=20
&amp;ordering=current_price
&amp;sort=asc
&amp;filter=experience_range:0,45
&amp;filter=price_range:15,500
</code></pre></div></div>
<p>We use this to provide a sensible default experience for all users when first loading the application.</p>

<h2 id="excluding">Excluding</h2>

<p><strong>Note</strong></p>
<ul>
  <li>Pass in records to exclude by separating them with a pipe <code class="language-plaintext highlighter-rouge">|</code></li>
  <li>Use the <code class="language-plaintext highlighter-rouge">_id</code> field from a specific record ` “_id”: “6340611”,` to exclude it from results</li>
  <li>The excluded row is simply omitted from the result set, it is not deleted.</li>
  <li>Since the excluded rows are not part of the result set returned, they are also not a part of any calculations or aggregations.</li>
  <li>Since the excluded rows are not part of the result set returned, they will not be included in any exported file.</li>
</ul>

<p><a href="https://api.gsa.gov/acquisition/calc/v3/api/ceilingrates/?search=idv_piid:GS10F0303V&amp;page=1&amp;page_size=100&amp;exclude=6275099|6275111|6275123">https://api.gsa.gov/acquisition/calc/v3/api/ceilingrates/?search=idv_piid:GS10F0303V&amp;page=1&amp;page_size=100&amp;exclude=6275099|6275111|6275123</a></p>
