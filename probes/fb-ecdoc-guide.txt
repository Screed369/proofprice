         <div class="paragraph">
            <p>All services return dates in <code>dd/MM/yyyy</code> format.</p>
         </div>
      </div>

      <div class="sect2">
         <h3 id="_how_date_filtering_works"><a class="link" href="#_how_date_filtering_works">How Date filtering works</a></h3>
         <div class="paragraph">
            <p>"BeginDate" and "EndDate" parameters restrict the entire week, whereas "Months" parameter only applies to the starting date of the week of the Marketing Year.</p>
         </div>
         <div class="paragraph">
            <p>In other words "Months" is based only on "Begin Date" and this behaviour is consistent through all sectors.</p>
         </div>
      </div>

      <div class="sect2">
         <h3 id="_sorting"><a class="link" href="#_sorting">Sorting mechanism</a></h3>
         <div class="paragraph">
            <p>By default prices APIs return results in an ordered manner. Unless stated in a specific sector, the priority follows the below order :
            <ol>
               <li>Begin Date in reverse chronological order</li>
               <li>Member State Name in alphabetical order</li>
            </ol>
            <p>
               For weekly TAXUD imports & exports APIs the ordering priority is as follows :
            <ol>
               <li>Marketing Year in reverse chronological order</li>
               <li>Week in reverse chronological order</li>
               <li>Member State Name in alphabetical order</li>
               <li>TARIC 10 code in ascending order</li>
            </ol>
            <p>
               For the CMEF Indicators values the ordering priority is as follows :
            <ol>
               <li>Year in reverse chronological order</li>
               <li>Indicator in ascending order</li>
               <li>Sub-indicator in ascending order</li>
               <li>Parameter in ascending order</li>
               <li>Code in ascending order</li>
               <li>Source in ascending order</li>
               <li>Member State Name in alphabetical order</li>
            </ol>
         </div>
